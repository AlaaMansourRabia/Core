# Design Tokens

Wakecore uses CSS custom properties as design tokens, defined in `@wakecap/core-tokens`. All colors use the OKLCH color space for perceptual uniformity.

## Spacing

Base spacing unit: `--spacing: 0.25rem` (4px)

Tailwind CSS 4 uses this as the spacing scale multiplier. For example, `wwc:p-4` = `1rem` (16px).

## Usage with Tailwind CSS 4

All Wakecore utility classes use the **`wwc:`** prefix to avoid collisions with consumer styles.

Tokens are mapped to Tailwind utilities via the `@theme inline` directive:

```css
@theme inline {
	--color-primary: var(--primary);
	--color-secondary: var(--secondary);
	--color-destructive: var(--destructive);
	/* ... */
}
```

This means you can use them directly in Tailwind classes (with the `wwc:` prefix):

```tsx
<div className="wwc:bg-primary wwc:text-primary-foreground">
  Primary colored element
</div>

<div className="wwc:border wwc:border-border wwc:rounded-lg">
  Bordered container
</div>
```
